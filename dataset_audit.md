# Dataset Audit and Integrity Report

This document describes the dataset structure, integrity checks, and
data-quality considerations for the Brain Tumor MRI Classification project.

## Dataset Overview

The project uses a four-class brain MRI image classification dataset:
- Glioma
- Meningioma
- Pituitary Tumor
- No Tumor

The dataset is used for research and educational experimentation in
medical image classification.

## Dataset Location

The dataset is not included in this repository. Configure the dataset
location locally according to the paths expected by the project's
configuration and data-loading scripts.
